# Mousecape Capes

A collection of `.cape` cursor files for [Mousecape](https://github.com/alexzielenski/Mousecape), a macOS tool for customizing the system cursor.

## Capes

| Cape | File |
| --- | --- |
| macOS 15 Sequoia | `com.alexzielenski.mousecape.dump.04C78452-1EE0-40FA-9286-8EA143EB593F.cape` |
| macOS 26 Tahoe | `com.alexzielenski.mousecape.dump.cape` |
| macOS 27 Golden Gate | `com.alexzielenski.mousecape.dump.737D2E3A-03B6-4EF9-BF52-3A0E651AD488.cape` |

These are dumps of the system cursors from the listed macOS versions, made with Mousecape's dump feature.

## Usage

1. Install [Mousecape](https://github.com/alexzielenski/Mousecape).
2. Clone this repo into `~/Library/Application Support/Mousecape/capes`, or open a `.cape` file to import it.
3. Select a cape in Mousecape and click **Apply**.
